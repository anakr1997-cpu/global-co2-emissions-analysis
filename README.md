# Global CO₂ Emissions Analysis | Tableau Dashboard

## Project Overview

Developed an interactive Tableau dashboard to explore global carbon dioxide (CO₂) emissions, population, and historical emissions trends across countries. The dashboard allows users to compare emissions patterns, examine geographic differences, and explore how countries contribute to global CO₂ emissions.

![Global CO₂ Emissions Dashboard](CO2%20dashboard.png)

## Tools & Skills

- **Tableau:** Dashboard development and interactive data visualization
- **Data Analysis:** Trend analysis and country-level comparisons
- **Data Visualization:** Geographic maps, scatter plots, and time-series charts
- **Interactive Reporting:** Filters and configurable Top N parameters

## Dashboard Features

- **Geographic Map:** Visualizes CO₂ emissions per capita across countries.
- **Scatter Plot:** Compares CO₂ emissions and population by country for 2021.
- **Time-Series Chart:** Displays historical changes in countries' shares of global CO₂ emissions.
- **Country Filter:** Allows users to focus on selected countries.
- **Top N Parameter:** Enables users to adjust the number of countries included in comparisons.

## Project Highlights

- Built an interactive dashboard combining three visualization types.
- Analyzed historical emissions patterns and country-level differences.
- Implemented filters and a configurable Top N parameter to support customized exploration.
- Presented environmental data in an accessible format for comparative analysis.
